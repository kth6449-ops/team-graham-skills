## 2. 투자유치 사업계획서 (IR Business Plan)

### 2-1. 표준 구조 (10~15장 기준)

```
1.  Executive Summary        한 장에 전체 요약 — 여기서 승부가 갈린다
2.  Problem                  고객이 실제로 돈을 쓰고 있는 문제
3.  Solution                 제품 데모 수준의 구체성
4.  Why Now                  왜 지금인가 (시장 변곡점)
5.  Market Size              TAM/SAM/SOM — Bottom-up 산정 필수
6.  Product                  핵심 기능 3가지 + 로드맵
7.  Traction                 ★가장 중요 — 숫자로 증명
8.  Business Model           단가 × 고객수 = 매출 구조 명확화
9.  Unit Economics           LTV/CAC, Payback Period
10. Competition              포지셔닝 맵 + 진입장벽
11. Go-to-Market             획득 채널과 비용
12. Financials               3개년 P&L, 현금흐름, 손익분기 시점
13. Team                     왜 이 팀이어야 하는가
14. Ask & Use of Funds       얼마를, 어디에, 그래서 무엇을 달성
15. Milestones               다음 라운드까지의 검증 목표
```

### 2-2. Traction 표현 규칙 (VC가 가장 먼저 보는 곳)

```
❌ 나쁜 예: "다수의 고객사와 논의 중이며 긍정적 반응"
✅ 좋은 예:
   유료 고객: 3사 (2026.02 첫 계약)
   MRR: 1,200만원 (MoM +18%, 4개월 연속 성장)
   파이프라인: 11사 (합산 예상 ARR 4.8억)
   Retention: 100% (해지 0건, 계약 기간 평균 24개월)
   레퍼런스 성과: A사 OEE 62%→71% (+9%p), 연 환산 절감 3.2억원
```

**Traction이 부족할 때의 정직한 대안**
- 초기 단계면 **Problem 검증의 강도**로 대체: 인터뷰 N건, 유료 전환 의향 N%
- 절대 하지 말 것: MOU·협약·"논의 중"을 성과로 포장 → 심사역이 즉시 간파

### 2-3. TAM/SAM/SOM 산정 — Bottom-up 필수

```
❌ Top-down (신뢰 상실): "국내 제조 AI 시장 3조원 × 1% = 300억"

✅ Bottom-up (신뢰 확보):
   TAM = 국내 제조업 50~500인 사업체 수 × 연간 지불가능액
       = 12,400개사 × 3,600만원/년 = 4,464억원
       [출처: 통계청 광업제조업조사, 자사 견적 실적 기준]

   SAM = 그중 데이터 수집 인프라 보유 또는 도입 가능 = 약 32%
       = 3,968개사 × 3,600만원 = 1,428억원

   SOM = 3년 내 확보 목표 (영업 커버리지 기준)
       = 영업 3인 × 연 8개사 × 3년 = 72개사 = 26억원 ARR
```

**SOM은 반드시 "우리 조직이 실제로 도달 가능한 수"로 산정한다. 시장 점유율 %로 계산하면 신뢰를 잃는다.**

### 2-4. Unit Economics 표준

```python
UNIT_ECONOMICS = {
    "ARPA":     "고객당 연평균 매출 (초기구축비 제외 구독 기준)",
    "Gross Margin": "구독 매출 - (인프라 + 지원인건비)",
    "CAC":      "(마케팅비 + 영업인건비) / 신규 고객수",
    "LTV":      "ARPA × Gross Margin% × 평균 계약유지연수",
    "LTV/CAC":  "3.0 이상 목표 (1.0 미만이면 사업모델 재설계)",
    "Payback":  "CAC / (월 ARPA × GM%) — 18개월 이내 목표",
    "NRR":      "기존 고객 매출 유지·확장률, 100% 이상이면 우수",
}
```

**SME 대상 B2B SaaS 벤치마크 (참고)**
| 지표 | 위험 | 보통 | 우수 |
|------|------|------|------|
| LTV/CAC | < 1.5 | 1.5~3.0 | > 3.0 |
| Payback | > 24개월 | 12~24개월 | < 12개월 |
| Gross Margin | < 50% | 50~70% | > 70% |
| Churn (연) | > 20% | 10~20% | < 10% |
| NRR | < 90% | 90~110% | > 110% |

## 3. 금융기관 대출용 사업계획서

### 3-1. 여신 심사의 본질

> 은행은 **성장 가능성이 아니라 상환 가능성**을 본다.
> "우리는 3년 후 100억 매출" 보다 "다음 12개월 매달 이자를 낼 현금이 있다"가 중요하다.

### 3-2. 필수 구성

```
1. 기업 개요            설립, 대표 이력, 주주 구성, 조직
2. 사업 현황            주요 제품, 매출 추이(3개년 실적)
3. 자금 조달 목적       ★ 용도를 구체적으로 (운전자금/시설자금 구분)
4. 상환 계획            ★ 핵심 — 월별 현금흐름으로 상환 재원 증명
5. 재무제표 분석        3개년 요약 + 주요 재무비율
6. 수주 현황·계약서      상환 재원의 근거 (계약서 사본 첨부)
7. 담보·보증 사항        보유 담보, 신용보증기금/기술보증기금 활용
8. 리스크 및 대응        매출 감소 시 대응 시나리오
```

### 3-3. 심사역이 보는 재무비율

| 비율 | 산식 | 기준 | 의미 |
|------|------|------|------|
| 부채비율 | 부채/자본 | < 200% | 재무 안정성 |
| 유동비율 | 유동자산/유동부채 | > 100% | 단기 지급능력 |
| 이자보상배율 | 영업이익/이자비용 | > 1.5배 | **상환 여력 핵심** |
| 매출채권회전율 | 매출/평균매출채권 | 업종평균 이상 | 회수 능력 |
| 영업현금흐름 | - | 양(+) 유지 | **가장 중요** |

### 3-4. 정책자금 트랙 (SME 필수 지식)

| 기관 | 주요 상품 | 특징 |
|------|----------|------|
| 중소벤처기업진흥공단 | 창업기반지원, 신시장진출, 혁신성장 | 저리, 직접대출, 사업계획 심사 비중 큼 |
| 기술보증기금 | 기술평가보증 | **기술력으로 보증** — 기술 사업계획 중요 |
| 신용보증기금 | 일반보증, 스타트업 보증 | 신용 기반 |
| 지자체 | 중소기업육성자금 | 이차보전, 지역 기업 우대 |

> **Alex 실무 팁**: 기술보증기금은 기술평가등급(T1~T10)이 핵심이다.
> 특허·인증·R&D 실적·기술인력 비중이 등급을 좌우하므로 사업계획서에 **기술 자산을 정량 표기**한다.

### 5-1. 구조

```
1. 전년도 실적 리뷰        계획 대비 달성률, 미달 원인
2. 시장·경쟁 환경 전망
3. 연간 목표 (OKR/KPI)     전사 → 부문 → 팀 계층화
4. 부문별 실행 계획
5. 예산 계획               수익 예산 + 비용 예산
6. 인력 운영 계획
7. 주요 리스크 및 대응
8. 분기별 마일스톤 및 점검 체계
```

### 5-2. 목표 수립 원칙

| 원칙 | 내용 |
|------|------|
| **Top-down × Bottom-up** | 경영 목표 제시 → 현장 실행계획 수립 → 갭 조정 |
| **3-Scenario** | 보수(70%) / 기본(100%) / 도전(130%) — 기본 시나리오로 예산 편성 |
| **선행지표 포함** | 매출(후행)만이 아니라 파이프라인·활동량(선행) 지표 병기 |
| **분기 리뷰 강제** | 연 1회 수립 후 방치 금지, 분기별 재예측(Rolling Forecast) |

## 6. 고객 제안서 / RFP 대응

### 6-1. 수주 제안서 표준 구조

```
1. 제안 요약               고객 문제 → 우리 해법 → 기대효과 (1장)
2. 고객 현황 및 문제 정의   ★ 고객이 말한 것을 고객의 언어로 되돌려줌
3. 제안 솔루션             기능이 아니라 문제 해결 방식으로 서술
4. 구축 범위 및 방법론      Hybrid V-Cycle 게이트 기반 (v5.0 표준)
5. 수행 일정 및 마일스톤
6. 투입 인력 및 조직        역할·경력 명시
7. 기대 효과 (정량)         ★ ROI 계산 근거 제시
8. 유사 구축 실적
9. 견적 및 계약 조건
10. 리스크 관리 방안
```

### 6-2. ROI 제시 공식 (SME 설득 핵심)

```
연간 절감 효과 = ①생산성 개선 + ②품질비용 절감 + ③인건비 절감 + ④기회손실 회피
투자 회수기간 = 총 투자액 / 연간 절감 효과

예시 (제조 SME, 연매출 120억):
① OEE 62%→68% (+6%p) → 추가 생산능력 = 연 7.2억 매출 여력 (마진 15% = 1.08억)
② 불량률 3.2%→2.4% → 품질비용 절감 = 연 0.96억
③ 데이터 집계 수작업 제거 = 월 60시간 × 3만원 × 12 = 0.22억
합계 연간 효과 ≈ 2.26억 / 투자액 0.8억 → 회수기간 4.2개월
```

> **주의: 효과는 반드시 보수적으로 산정한다.** 과대 추정은 검수 단계에서 부메랑이 된다.
> 최소/기대/최대 3개 시나리오로 제시하고 **최소 시나리오로도 ROI가 성립함**을 보인다.

### 6-3. RFP 대응 절차

```
1. RFP 요구사항 전건 분해 → 요구사항 대응표(Compliance Matrix) 작성
2. 필수/선택/가점 항목 구분, 미충족 항목 식별
3. 미충족 항목 대응 전략: 파트너 협력 / 대안 제시 / 명시적 제외
4. 평가 배점표 역산 → 배점 높은 항목에 분량·근거 집중
5. Sam·Peter에게 기술 사양 요청 (BSL-{PROJ}-PROP-{SEQ} 발행)
6. 제출 전 Graham 검토 게이트 필수
```
