## 1. 아이디어 도출 (Ideation)

### 1-1. 5가지 도출 경로 — **최소 3개 경로를 병행한다**

한 가지 경로만 쓰면 편향된다. Alex는 아래 중 **3개 이상**을 교차 적용한다.

#### 경로 A. Pain-driven (고객 고통 기반) — 가장 신뢰도 높음
```
고객 관찰/인터뷰 → 반복되는 불평 수집 → "지금 이 문제를 어떻게 해결하고 있나?" 질문
→ 현재 해결책의 비용(시간·돈·리스크) 측정 → 그 비용이 우리 솔루션 가격보다 큰가?

핵심 질문: "이 문제 때문에 지금 돈을 쓰고 있는가?"
   YES → 유효 (예산이 이미 존재)
   NO  → 위험 (신규 예산 설득 필요, 판매주기 2~3배)
```

#### 경로 B. Asset-driven (보유 역량 기반) — BESOLT에 가장 현실적
```
보유 자산 목록화:
  기술자산   Edge-Center AI, 시계열 처리, 제조 데이터 파이프라인
  고객자산   기존 고객사 N개, 현장 접근권, 신뢰 관계
  지식자산   제조 도메인 노하우, 정부사업 대응 역량
  인적자산   Sam·Peter의 풀스택 구현력

→ "이 자산으로 다른 누가 못 하는 무엇을 할 수 있는가?"
→ 자산 2개 이상을 결합할 때 모방 난이도가 급상승한다
```

#### 경로 C. Trend-driven (변곡점 기반)
```
변곡 신호 탐색:
  규제 변화     중대재해처벌법, 개인정보 규제, ESG 공시 의무
  기술 변화     LLM 비용 하락, Edge 연산 성능 향상
  구조 변화     제조 인력 고령화, 물류비 상승, 최저임금
  자금 변화     정부 예산 방향, 정책자금 트랙 신설

→ "Why now?" 질문에 답할 수 있는가?
→ 답할 수 없으면 그 아이디어는 이미 늦었거나 아직 이르다
```

#### 경로 D. Jobs-to-be-Done (해결하려는 '일' 기반)
```
JTBD 문장 형식:
"{상황}일 때, 나는 {동기}하고 싶다. 그래서 {기대 결과}를 얻을 수 있도록."

예) "월말 결산할 때, 나는 제품별 실제 원가를 즉시 알고 싶다.
     그래서 적자 품목을 그달 안에 정리할 수 있도록."

→ 고객은 제품을 사는 게 아니라 '일'을 시키기 위해 고용한다
→ 경쟁자 = 같은 일을 하는 모든 대안 (엑셀, 외주, 그냥 참기 포함)
```

#### 경로 E. Blue Ocean ERRC (가치 재구성)
```
기존 산업의 경쟁 요소를 나열한 뒤 4가지로 재배치:

Eliminate  제거   업계가 당연시하지만 고객이 원치 않는 것
Reduce     감소   과잉 제공되고 있는 것
Raise      증가   부족하게 제공되는 것
Create     창조   업계가 제공한 적 없는 것

예) 제조 MES 시장 ERRC
  Eliminate  현장 커스터마이징 3개월 (표준화로 제거)
  Reduce     기능 개수 (SME는 20%만 사용)
  Raise      구축 속도 (3개월 → 2주)
  Create     경영진용 원가 연동 뷰
```

### 1-2. 아이디어 발산 규칙

| 규칙 | 내용 |
|------|------|
| **수량 우선** | 1차 발산에서 최소 15개. 좋은 것만 내려 하면 발산이 죽는다 |
| **판단 금지** | 발산 단계에서 실현가능성 평가 금지. 스크리닝은 §2에서 |
| **조합 강제** | 서로 다른 경로에서 나온 아이디어 2개를 강제 결합해 본다 |
| **금지 아이디어 명시** | 규제 위반, 핵심가치 배치, 기존 고객 이해충돌은 즉시 제외 |

## 2. 아이디어 스크리닝 (Screening)

> **Graham 맹점 대응**: 여기서 반드시 **숫자로 잘라낸다.**
> 스크리닝 없이 여러 아이디어를 병렬 검토하면 결정이 무한 지연된다.

### 2-1. 1차 스크리닝 — 5개 관문 (Knock-out)

하나라도 NO면 **즉시 탈락**. 논의하지 않는다.

```
[1] 규제/법적 진입이 가능한가?            NO → 탈락
[2] 고객이 이 문제에 이미 돈을 쓰고 있는가?  NO → 보류(장기 백로그)
[3] 우리 자산으로 12개월 내 MVP가 되는가?   NO → 탈락
[4] 기존 사업과 이해충돌이 없는가?          NO → 탈락
[5] 최소 3개 고객사가 실재하는가?          NO → 탈락
```

### 2-2. 2차 스크리닝 — 4축 정량 평가

각 축 1~5점, 가중 합산. **15점 미만은 진행하지 않는다.**

| 축 | 세부 항목 | 가중치 |
|----|----------|--------|
| **시장 매력도** | 시장 규모 / 성장률 / 지불의사 / 경쟁 강도 | 30% |
| **적합성** | 기존 역량 활용도 / 기존 고객 재활용 / 브랜드 정합 | 30% |
| **실행 가능성** | 필요 인력 확보 / 소요 자본 / 개발 기간 | 25% |
| **리스크** | 규제 / 경쟁 반응 / 기존 사업 잠식 (역점수) | 15% |

```markdown
| 아이디어 | 시장매력도 | 적합성 | 실행가능성 | 리스크(역) | 가중점수 | 판정 |
|---------|----------|--------|-----------|-----------|---------|------|
| A. 물류 SME 재고 AI | 4 | 4 | 4 | 4 | 4.0 | ✅ 진행 |
| B. 건설 안전 영상분석 | 4 | 2 | 2 | 3 | 2.7 | ❌ 보류 |
| C. F&B 원가 자동화 | 3 | 4 | 5 | 4 | 3.9 | ✅ 진행 |
```

### 2-3. 스크리닝 산출 규칙

- 최종 진행 후보는 **최대 2개**. 3개 이상이면 자원이 분산되어 전부 실패한다.
- 탈락 아이디어는 삭제하지 말고 **백로그에 사유와 함께 보존** — 조건이 바뀌면 재부상한다.

## 3. 프레임워크 툴킷 — 적용 방법 포함

> **⚠️ 프레임워크 남용 경고 (Graham 과잉 모델링 맹점 대응)**
> 프레임워크는 **질문에 답하기 위한 도구**이지 문서를 채우는 재료가 아니다.
> **모든 프레임워크를 다 쓰지 않는다.** §4의 선택 매트릭스로 3~4개만 고른다.

### 3-1. PESTEL — 거시 환경 분석

**언제 쓰는가**: 신규 시장·신규 업종 진입 시, "Why now"를 증명해야 할 때

| 축 | 확인 질문 | BESOLT 적용 예시 (제조 AI) |
|----|----------|--------------------------|
| **P** Political | 정책·정부 방향이 우호적인가 | 제조AX 국정과제, 스마트공장 예산 지속 |
| **E** Economic | 경기·비용 구조가 도입을 촉진하는가 | 인건비 상승 → 자동화 투자 유인 증가 |
| **S** Social | 인구·인식 변화가 있는가 | 제조 인력 고령화, 청년 기피 → 무인화 압력 |
| **T** Technological | 기술 성숙도가 임계점을 넘었는가 | LLM 추론비 하락, Edge 연산 성능 향상 |
| **E** Environmental | 환경 규제·ESG 요구가 있는가 | 탄소배출 공시, 에너지 사용 최적화 수요 |
| **L** Legal | 법적 제약·의무가 있는가 | 중대재해처벌법 → 안전 데이터 관리 의무 |

**작성 규칙**
```
❌ 나쁜 예: 6개 축을 균등하게 나열 (형식적 채우기)
✅ 좋은 예: 6개 축 중 사업에 실제 영향을 주는 2~3개만 심층 분석 +
           나머지는 "영향 미미"로 1줄 처리
→ 마지막에 반드시 So What: "따라서 지금이 진입 시점인 이유는 ___이다"
```

### 3-2. 3C — 사업 성립 요건 점검

**언제 쓰는가**: 아이디어를 사업으로 전환할 때 가장 먼저. **가장 빠르고 실용적인 프레임.**

```
Customer  고객    누가, 얼마나 많이, 무엇에 돈을 쓰는가
Competitor 경쟁   현재 그 돈을 누가 받고 있는가 (엑셀·외주·방치 포함)
Company   자사    우리가 그 돈을 가져올 수 있는 이유는 무엇인가
```

**3C 작성 템플릿**
```markdown
### Customer
- 세그먼트: 제조 SME 50~300인, 다품종 소량생산
- 규모: 국내 12,400개사 (통계청 광업제조업조사)
- 현재 지출: 원가 관리에 회계인력 1~2명 + ERP 커스터마이징 연 2천만원
- 미충족 니즈: 실시간 제품별 원가 파악 불가 (월말에야 확인)

### Competitor
- 직접 경쟁: 더존 ERP 원가모듈, 영림원 (기능 과다, 구축 6개월)
- 간접 경쟁: 엑셀 수작업 (실제 1위 경쟁자), 회계법인 외주
- 미대응 영역: 실시간성, SME 가격대, 2주 구축

### Company
- 우위: 제조 데이터 파이프라인 보유, Edge 처리로 서버비 절감
- 열위: 브랜드 인지도, 영업 조직 규모
- 결론: 가격·속도로 진입, 레퍼런스 확보 후 확산
```

> **3C의 핵심은 세 번째 문장이다**: "그래서 우리가 이길 수 있는 이유"가 나오지 않으면 사업이 아니다.

### 3-3. Porter's 5 Forces — 산업 수익성 구조

**언제 쓰는가**: 시장이 매력적으로 보일 때, **정말 돈이 남는 구조인지** 검증

| Force | 확인 질문 | 위험 신호 |
|-------|----------|----------|
| 신규 진입 위협 | 진입장벽이 있는가 | 오픈소스로 6개월이면 복제 가능 |
| 공급자 교섭력 | 핵심 공급자에 종속되는가 | LLM API 단일 벤더 의존 |
| 구매자 교섭력 | 고객이 가격을 좌우하는가 | 대기업 1개사 매출 비중 50%+ |
| 대체재 위협 | 다른 방식으로 해결 가능한가 | 엑셀+사람으로 충분 |
| 기존 경쟁 강도 | 가격 경쟁이 심한가 | 다수 업체 유사 기능, 차별화 실패 |

**산출**: 5개 중 **가장 강한 압력 1개**를 식별하고, 그것에 대한 대응 전략을 명시한다.

### 3-4. SWOT → TOWS — 전략 도출

**⚠️ SWOT만 쓰면 나열에 그친다. 반드시 TOWS로 전략을 뽑아낸다.**

```
        │ Opportunities        │ Threats
────────┼─────────────────────┼──────────────────────
Strength│ SO 공격 전략         │ ST 방어 전략
        │ 강점으로 기회 극대화  │ 강점으로 위협 회피
────────┼─────────────────────┼──────────────────────
Weakness│ WO 보완 전략         │ WT 회피/철수 전략
        │ 기회 위해 약점 보완   │ 최소화 또는 진입 포기
```

**예시 (BESOLT 물류 진입)**
| 조합 | 전략 |
|------|------|
| SO | 제조 데이터 역량(S) × 물류 디지털화 예산 증가(O) → 물류 SME 대상 재고 AI 우선 출시 |
| ST | Edge 처리 역량(S) × 대형 벤더 진입(T) → 온프레미스·보안 요구 세그먼트 선점 |
| WO | 물류 도메인 부족(W) × 파트너 수요(O) → WMS 벤더와 제휴로 도메인 확보 |
| WT | 영업조직 부족(W) × 가격 경쟁(T) → 직접 영업 확대 대신 채널 전략 |

### 3-5. Business Model Canvas (BMC) — 사업 구조 전체 점검

**언제 쓰는가**: 아이디어가 스크리닝을 통과한 직후, 사업 구조를 1페이지로 압축할 때

```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│ Key       │ Key      │ Value    │ Customer │ Customer │
│ Partners  │Activities│Proposition│Relations│ Segments │
│           ├──────────┤          ├──────────┤          │
│           │ Key      │          │ Channels │          │
│           │Resources │          │          │          │
├───────────┴──────────┴─────┬────┴──────────┴──────────┤
│ Cost Structure             │ Revenue Streams          │
└────────────────────────────┴──────────────────────────┘
```

**BESOLT 작성 시 필수 점검 3가지**
1. Value Proposition이 고객 세그먼트별로 **다르게** 서술되었는가 (경영진 vs 현장)
2. Revenue Streams가 **초기구축비 + 구독 + 유지보수**로 분해되었는가
3. Cost Structure에 **고객 성공(CS) 비용**이 반영되었는가 — SME B2B에서 가장 과소평가되는 항목

### 3-6. Lean Canvas — 초기 아이디어 검증용 (BMC의 스타트업 변형)

BMC와 달리 **문제·해결책·핵심지표·불공정 우위**를 강조한다. 아이디어 초기에 더 적합.

```
Problem (상위 3개)  │ Solution (상위 3개)  │ UVP  │ Unfair Advantage │ Customer Segments
Existing Alternatives│ Key Metrics          │      │ Channels         │ Early Adopters
Cost Structure                              │ Revenue Streams
```

> **Unfair Advantage 칸이 비어 있으면 그 사업은 복제된다.**
> "기술력이 좋다"는 Unfair Advantage가 아니다. 고객 데이터, 독점 계약, 규제 인증, 전환비용이 답이다.

### 3-7. Value Proposition Canvas — 가치 제안 정밀화

```
[Customer Profile]                [Value Map]
Jobs   고객이 하려는 일       ←→   Products & Services
Pains  그 과정의 고통         ←→   Pain Relievers
Gains  기대하는 이득          ←→   Gain Creators
```

**Fit 판정**: Pain 상위 3개 중 **2개 이상**에 대응하는 Pain Reliever가 있어야 Fit.
1개 이하면 "있으면 좋은 것"이지 "사야 하는 것"이 아니다.

### 3-8. STP — 세분화·타겟팅·포지셔닝

```
Segmentation  시장을 나눈다     (업종 × 규모 × 성숙도 × 지역)
Targeting     하나를 고른다     (매력도 × 접근성 × 우리 적합성)
Positioning   한 문장으로 선다  ("___에게 ___를 제공하는 유일한 ___")
```

**포지셔닝 문장 템플릿**
```
{타겟 고객}에게 BESOLT는 {카테고리} 중에서
{차별 가치}를 제공하는 유일한 선택지다. 왜냐하면 {근거}이기 때문이다.

예) 제조 SME 50~300인에게 SOLT-BI는 원가관리 솔루션 중에서
    2주 내 구축과 실시간 제품별 원가를 제공하는 유일한 선택지다.
    왜냐하면 Edge 처리로 기존 ERP 개조 없이 데이터를 수집하기 때문이다.
```

### 3-9. TAM / SAM / SOM — 시장 규모 (기존 스킬 참조)

**Bottom-up 산정 필수.** 상세 방법론과 예시: `references/skills/corporate-business-planning.md` §2-3

```
TAM  전체 시장     = 대상 사업체 수 × 연간 지불가능액
SAM  유효 시장     = TAM × 우리 솔루션 적용 가능 비율
SOM  획득 목표     = 영업 인원 × 인당 연간 수주 × 기간  ← 조직 역량 기준
```

### 3-10. Ansoff Matrix — 성장 방향 선택

```
              기존 제품          신규 제품
기존 시장   │ 시장 침투        │ 제품 개발
           │ (리스크 낮음)     │ (리스크 중)
신규 시장   │ 시장 개발        │ 다각화
           │ (리스크 중)       │ (리스크 높음)
```

**BESOLT 적용**: 제조 고객에 SOLT-BI 추가 판매 = 제품 개발 / 물류 업종 진입 = 시장 개발
**원칙**: 다각화(신제품×신시장)는 기존 두 축에서 성공한 이후에만 시도한다.

### 3-11. Value Chain — 원가·차별화 지점 식별

고객사의 가치사슬 어디에 우리가 개입하는지 명시한다. **제안서 설득력의 핵심.**
```
조달 → 생산 → 물류 → 마케팅·영업 → 서비스
              ↑ SOLT-AI 개입 지점 (생산 효율)
       ↑ SOLT-BI 개입 지점 (원가 가시성)
```

## 5. 타당성 설득 구조 (Persuasion Architecture)

> 분석은 설득이 아니다. **분석 결과를 설득 구조로 재배열**해야 다음 단계로 넘어간다.

### 5-1. 설득의 4층 구조 — 위에서부터 읽어도 납득되게

```
[1층] 결론      우리는 ___를 해야 한다. 투자 ___원, 회수 ___개월.
   ↑
[2층] 근거 3개  ① 시장이 있다  ② 우리가 이긴다  ③ 지금이다
   ↑
[3층] 증거      각 근거마다 데이터 2개 이상 (출처 명시)
   ↑
[4층] 검증방법  이 판단이 틀렸다면 무엇으로 알 수 있는가 (Kill Criteria)
```

**Pyramid Principle**: 결론 → 근거 → 증거 순. 절대 반대로 쓰지 않는다.
읽는 사람은 1층만 읽고도 결정할 수 있어야 하고, 의심되면 2~4층으로 내려간다.

### 5-2. 증거의 신뢰도 위계 — **높은 것부터 배치**

| 등급 | 증거 유형 | 설득력 |
|------|----------|--------|
| **1등급** | 실제 계약·매출·유료 전환 | 최상 — 반박 불가 |
| **2등급** | 파일럿 실측 데이터 (고객사 개선 수치) | 높음 |
| **3등급** | 고객 인터뷰 (지불 의사 발언, N수 명시) | 중상 |
| **4등급** | 공신력 있는 통계 (통계청, 산업연구원) | 중 |
| 5등급 | 시장조사 보고서 (민간 리서치) | 중하 |
| 6등급 | 언론 기사 | 하 |
| **불가** | "~할 것으로 예상됨", 근거 없는 추정 | **사용 금지** |

**규칙: 핵심 주장 3개는 반드시 1~3등급 증거로 뒷받침한다.**

### 5-3. 반론 선제 대응 — 독자의 공포에 먼저 답한다

읽는 사람은 반드시 아래를 의심한다. **묻기 전에 답한다.**

| 예상 반론 | 대응 방식 |
|----------|----------|
| "시장이 정말 그만큼 큰가?" | Bottom-up 산정 근거 + 출처 + 보수 시나리오 병기 |
| "경쟁사가 하면 끝나는 거 아닌가?" | 진입장벽 명시 (전환비용·데이터·인증·계약) |
| "우리가 할 역량이 있나?" | 보유 자산 매핑 + 부족분에 대한 확보 계획 |
| "돈이 얼마나 드나?" | 3-Scenario 투자 규모 + 단계별 분할 투자 구조 |
| "실패하면 어떻게 되나?" | **Kill Criteria + 롤백 계획 + 매몰비용 한도** |

> **가장 강력한 설득은 리스크를 먼저 말하는 것이다.**
> 리스크를 숨긴 계획은 검토 과정에서 반드시 발각되고, 그 순간 전체 신뢰가 붕괴된다.

### 5-4. 정량 논리 필수 3종

```
① 시장 규모      Bottom-up TAM/SAM/SOM (출처 명시)
② 수익 구조      단가 × 고객수 × 유지기간 = LTV / CAC 대비 배수
③ 투자 회수      투자액 / 연간 순현금흐름 = 회수기간, NPV·IRR
```

**어느 하나라도 없으면 G0 게이트 상정 자격이 없다.**
